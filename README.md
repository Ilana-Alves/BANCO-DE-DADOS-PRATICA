EXERCICIOS PRATICOS REALIZADOS/ADS- TERCEIRO PERIODO:

Exercício 1: Consultas Básicas (SELECT e WHERE) Desafio: Selecione o nome e a cidade de todos os clientes que moram na cidade de 'São Paulo'.

Exercício 2: Inserção de Dados (INSERT)

Desafio: Insira um novo cliente no banco de dados com os seguintes dados:

Nome: Fernanda Oliveira

Email: fernanda@email.com

Cidade: Curitiba

Data de Cadastro: 2025-04-01

Exercício 3: Atualização e Exclusão (UPDATE e DELETE)

Desafio A: Atualize a cidade do cliente Carlos Souza para 'Niterói'.

Desafio B: Delete o pedido com o id_pedido igual a 4.

Exercício 4: Agrupamento e Ordenação (GROUP BY, ORDER BY e SUM)

Desafio: Faça uma consulta que mostre o valor total gasto em pedidos por cada cliente (id_cliente e a soma de valor_total). 
Ordene o resultado do maior valor para o menor.

Exercício 5: Junção de Tabelas (INNER JOIN)

Desafio: Crie uma consulta que exiba o nome do cliente, o id_pedido, o valor_total e a data_pedido de todos os pedidos cadastrados no sistema.
